# Aternative-Data-Research-Platform-for-quantitative-finance

## Project Overview 
Project design to extract alternative data and turn into usable insights 

## Problem Statement 
Alt data is hard to access and complex to turn into usable insights. However, alt data patterns are valuable and its patterns can reveal trends important for analysis.

## Proposed Solution & Target Audience 
This project is design to help financial and data analysis, data scientists and engineers, and portfolio managers to use alternative data without the time constraint of transforming the data into insights. The project is also designated to students leaning the process of working with data or equity research and analysis.  

## Long-term Vision 
Create a tool that can be used into hedge fund strategies to find opportunities in the market with alternative data.
